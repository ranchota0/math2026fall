# 成熟教案风格采用报告

## 采用的特征

| 成熟教案特征 | Phase 6 落实方式 | 样板证据 |
|---|---|---|
| 完整课堂链条 | 每节设置导入、探究、例练、纠错/迁移、检测、总结和作业 | 三份 `lessonplan.yml` 的 `process` |
| 问题驱动 | 每阶段 `teacher.questions` 非空，问题直接面向当前数学任务 | 共 46 个具体教师问题 |
| 一例一练一归纳 | 例题后同阶段或紧邻阶段安排对应练习，并写方法归纳 | 数轴表示数、移项例题、角和差/平分线 |
| 重视研究过程 | 让学生比较、画图、标注、口述依据、检验和订正 | `student.actions` 与 `expected_response` |
| 建模链条 | 应用环节写清设元、表示相关量、找相等关系、列方程和作答 | C05-L05 简单应用 |
| 回顾式小结 | 让学生回答研究对象、过程、方法和易错点 | 三节最后阶段 |
| 简短设计意图 | 每阶段 1 条，直接说明激活、降低难度、暴露错误或促进迁移 | 共 23 条设计意图 |
| 可用板书 | 板书包含课题、定义/法则、流程、关系式与易错提醒 | 三节第一页 |

## 主动修正的原稿问题

- 未复制“解诀”等错别字或原稿标点问题。
- 未复制重复编号、题干缺失和答案直接填入空格。
- 教学目标控制在 4 条，使用“说出、画出、判断、计算、说明”等可观察动词。
- 教学重点与难点分别写知识主线和认知障碍，不再完全相同。
- 学生活动、预期回答和估时全部填写。
- 板书不再只有课题名称。
- 课后反思不预设内容，三份均保持空白。
- 未复制反比例函数题目、初三难度或成熟教案图片。

## 数据结构采用

新版 `lessonplan.yml` 每阶段固定包含：

- `teacher.questions`
- `teacher.actions`
- `teacher.explanation`
- `teacher.correction`
- `teacher.example`
- `teacher.practice`
- `teacher.summary`
- `student.actions`
- `student.expected_response`
- `design_intent`
- `minutes`

另外保留 `page` 和可选 `figure`，用于四页背景模板的稳定分配和 TikZ 图形选择。生成器只读取 YAML，教案内容不再硬编码在 Python 中。

## 结论

本轮采用的是成熟教案的教学逻辑与郭老师偏好的问题链，不是原文复写。三节样板均符合初一教材范围、四页模板、45 分钟和空白反思要求，可作为候选生产标准；是否批量应用仍等待人工确认。
