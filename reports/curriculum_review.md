## 4. 特殊栏目处理

| 栏目 | 处理方式 | 理由 |
| --- | --- | --- |
| 阅读与思考 | 融入相邻新授或复习课 | 多数用于知识背景、应用拓展或模型意识提升，单独设课会拉长课时且目标不够集中。 |
| 探究与发现 | 融入相邻新授课 | 与当前知识点的推理或拓展直接相关，适合作为课堂探究或分层拓展。 |
| 图说数学史 | 融入复习或概念课 | 主要承担数学文化和视野拓展功能，适合在概念形成或章末复习中使用。 |
| 信息技术应用 | 与数学活动合并为活动课 | 与数据计算活动衔接紧密，独立设课必要性不强。 |
| 数学活动 | 原则上独立设课 | 教材活动页任务完整，需要操作、交流和展示时间。 |
| 小结 | 独立设章末复习课 | 章末小结与复习题承担结构化复习功能，应单独安排。 |
| 综合与实践 | 独立设课 | 综合任务跨页、问题链完整，需要完整课堂组织。 |
