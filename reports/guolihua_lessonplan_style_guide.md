# 郭立华课时教案风格规范（Phase 6 冻结稿）

## 定位

本规范用于和平街第一中学四页课时教学设计。教案写给任课教师，语言要简洁、可执行、能直接转化为课堂提问、板演、巡视和反馈。成熟教案只提供组织范式，数学知识范围仍以 `references/textbook.pdf` 和已确认课时边界为准。

## 一页概览

- 第一页：课题、课型、3—4 条可观察目标、1 条重点、1 条难点、2—3 种方法、真实教学手段、可手写板书。
- 第二至四页：6—8 个教学阶段，合计 45 分钟；每一阶段都有教师问题、教师动作、学生活动、预期回答、纠错处理、设计意图和估时。
- 第四页下部：课后反思保持完全空白。

## 教学链条

基本链条为“复习或情境引入 → 提出问题 → 探究/例题 → 对应练习 → 归纳方法 → 变式/纠错 → 当堂检测 → 回顾总结 → 分层作业”。环节之间必须有因果关系，前一问应自然产生后一项任务。

例题组织采用“一例一练一归纳”。原则上不得连续讲两个例题后才让学生动手。典型例题保留关键步骤和依据；第二变式优先转入练习或作业。

## 教师活动写法

教师活动至少回答四件事：

1. 问什么：写出具体问题，不写“提问学生”。
2. 做什么：说明展示、板演、组织互查、巡视或统计反馈的动作。
3. 讲什么：只写必要的定义、步骤、依据和结论。
4. 怎样纠错：指出预判错误及补救动作。

设计意图最多一至两句，只说明本环节的直接作用，如“激活等式性质，为解释移项变号提供依据”。

## 学生活动写法

学生活动使用具体动词：观察、回答、计算、画图、标注、讨论、归纳、互评、订正、检验。预期回答必须给出数学实质，不能只写“回答问题”或“完成练习”。

学生栏不使用黑色圆点堆叠；短句分段排列，给窄栏保留有效宽度。

## 四类课型

- 概念形成课：实例比较 → 抽象共同要素 → 正反例辨析 → 规范表示 → 应用与归纳。
- 运算技能课：复习依据 → 尝试 → 暴露问题 → 归纳步骤 → 示范 → 练习 → 纠错 → 检验。
- 应用建模课：真实情境 → 变量/不变量 → 数量关系 → 模型 → 求解 → 检验 → 实际解释。
- 几何探究课：观察图形 → 画/量/叠合/标注 → 猜想 → 用定义或关系说明 → 例练 → 图形归纳。

## 板书

板书至少包含课题、核心定义或法则、方法流程、典型关系式和一个易错提醒。板书条目控制在 4—6 条，句子短、层次清楚，能够在课堂上实际手写。

## 总结与作业

总结由学生回答回顾性问题：研究了什么、怎样研究、得到什么方法、哪里易错。教师只做补充和结构化。

作业使用“基础巩固 + 提升思考”两级，题目与本节目标一致；不在题干空格中预填答案，不引入教材后续知识。

## 禁止项

- 照抄成熟教案原题或初三难度；
- 复制错别字、重复编号和标点错误；
- 重点与难点写成同一句；
- 学生活动、预期回答或估时留空；
- 只写“教师讲解”“学生练习”；
- 预先填写课后反思；
- 用缩小到五号以下的方式强塞内容；
- 产生第 5 页、覆盖背景表格线或进入课后反思区域。

## 验收

每节必须通过 YAML 结构校验、45 分钟校验、XeLaTeX 编译、4 页 A4 纵向校验、4 张 PNG 渲染、日志错误和 Overfull 检查，并由人工逐页确认无越界、遮线、空白页、图文重叠和不合理密度。
