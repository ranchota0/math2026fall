# lesson_plans_v2 分页与版面优化报告

## 分页根因排查

- 未发现 `\newpage`、`\clearpage`、`\pagebreak`、`\Needspace`、`samepage`、`longtable`、`multirow` 强制分页结构。
- 实际原因是生成器显式为每组教学过程调用 `\LPBackgroundPage`，每次都会放入一张学校空白 PDF 背景并生成新页。
- 旧版还把较长教学环节封装为单个 `\LPProcessRow`，例如“应用例题与随堂练习”同时包含例题、答案、练习和补救，形成不可拆分大行。
- 本轮从生成器层修复：C05/C06 的长块被拆成“例题行”和“练习/补救行”，并把多个相关短环节连续放在同一页；没有逐份手工修改 PDF。

## 强制分页命令清理情况

- 未清理到强制分页命令；问题不来自 TeX 强制分页命令，而来自生成器显式分页。
- `LPProcessBox` 的页面级定位盒仍用于 PDF 背景叠加，但不再把每个短例题独立分配到新页。
- 后续若需要全自动自然跨页，应进一步把背景表格从 PDF 叠加改为可分页 LaTeX 表格；本轮保持学校 PDF 模板视觉样式不变。
